# Objective
The aim of this lesson is to provide an introduction to the **Gradient Boosting Machine (GBM) model**. We will create a baseline GBM model, interpret its results, and tune the model for optimal performance. Additionally, we will use insights from the GBM model to develop the best Generalized Linear Models (GLM) and compare them with other GLM models from Lesson 5. Finally, we will use the best GLM model, derived from GBM insights, to set final premium prices and understand how model coefficients are used in premium calculations.
